## Findings-provenance note (why this file exists)

The audit's originating 27-line-item findings list (pre-merge, pre-dedup) was never committed
to this repo — it existed only as narrative prose in an external memory store, which meant a
later audit could not re-derive individual finding text or numbering, only re-verify at the
7-cluster level (all 7 clusters were independently re-confirmed CLOSED-VERIFIED against current
HEAD during the 2026-08-03 re-audit). **Rule going forward: all future audit findings MUST land
in this repo as `audit/YYYY-MM-DD-findings.json`** (this file's schema — one JSON array, each
item carrying `id`/`severity`/`dimension`/`file`/`line`/`claim`/`evidence`/`verification`), so
the next audit can do true per-finding closure tracking instead of cluster-level approximation.
